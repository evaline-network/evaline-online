# EvaBot & Evaline Online // Modular Enterprise Ecosystem

Autonomous AI agent platform, EvaLine Consilium decision matrix, and cloud infrastructure deployed on **Google Cloud Platform (GCP)**.

- **Production Portal:** [https://evaline.online](https://evaline.online) (Corporate Manifesto & Consilium)
- **Voice & Control Center:** [https://evabot.online](https://evabot.online)
- **Live Network Graph:** [https://evaline.network](https://evaline.network)
- **Edge Proxy:** `evaline-micro-vm` (e2-micro Always Free, Iowa, us-central1-a)
- **Compute Core:** `evabot-agent-vm` (c3-standard-8 Sapphire Rapids, Frankfurt, europe-west3-a)
- **AI Core:** Google AI Pro (Gemini 2.0 / 1.5 Pro) with 2,000,000 token context window + EvaLine Consilium Multi-LLM Debate
- **Security:** Private WireGuard Mesh (Tailscale), TLS 1.3, HTTP/3 QUIC (Caddy)

## Corporate Manifesto & Consilium Engine

The flagship [https://evaline.online](https://evaline.online) features:
1. **Евалайн Консилиум (Consilium Engine):** 4-stage adversarial multi-model pipeline (Decomposition, Parallel Multi-LLM Debate, Adversarial CISO/QA Audit, Consensus Synthesis) for enterprise decision making.
2. **Industrial Material Science Integration:** Real-world data integration from EvaLine polymer plant in Chernomorsk and EU logistics hub in Bratislava (EVA sheets, tatami, marine teak, cow mats, certified under ISO 9001, CE, SES, UNIC).
3. **Fluid Responsive Typography:** Fully elastic design using Google Roboto family (`Roboto`, `Roboto Condensed`, `Roboto Mono`, `Roboto Slab`, all weights 100–900).
4. **Interactive 94-Model LLM Catalog:** Dual-tier matrix (62 Free, 32 Paid models) with multi-criteria real-time sorting (IQ, recency, cost, context window).

## Architecture Overview

1. **Screen 1:** Gemini Conversational Core & Live Gemini Voice Assistant
2. **Screen 2:** Live Physical & Virtual Cluster Telemetry (10 vCPUs, 33 GB RAM, 120 GB Storage)
3. **Screen 3:** Financial & OpEx Cost Analytics (Strictly USD $ and EUR €)
4. **Screen 4:** AI Model Hub (94 Frontier & Open-Source LLMs)
5. **Screen 5:** Omnichannel Messenger Gateways (Telegram, WhatsApp, Viber, Facebook Messenger)
6. **Screen 6:** Chronological Audit Log & Multilingual Neural Voice Engine (EN / RU / UK)

## Standalone Terminal CLI

Run the standalone interactive terminal client directly via Python:

```bash
python3 evabot-cli.py
```

Run non-interactive automated self-test:

```bash
python3 evabot-cli.py --test
```
